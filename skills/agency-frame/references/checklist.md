# FRAME — gate checklist

## Domain gate (signed by a product/analysis agent)

- [ ] Goal is 1–3 sentences and contains a single intent.
- [ ] ≥ 2 success criteria, each with a number or verifiable state.
- [ ] Every criterion is checkable from an artifact or a metric.
- [ ] Scope.In names what will be produced.
- [ ] Scope.Out names at least one thing explicitly excluded.
- [ ] Constraints are actionable (not "fast", not "high quality").

## Process gate (signed by PM)

- [ ] File lives at `docs/agency-flow/<slug>/00-frame.md`.
- [ ] Domain profile declares producer domains only.
- [ ] Deliverable type is one of the canonical values.
- [ ] `research?` and `measure?` are explicit `yes`/`no` (not blank).
- [ ] Staffing is confirmed achievable (PM has verified available agents).
- [ ] Every criterion is measurable with an agent that exists.
- [ ] `## Assigned team` and `## Gates` blocks are present.
- [ ] No criteria were added after staffing confirmation.

## Rejection triggers

- Goal written as a task list ("do X, then Y").
- Criteria that are qualitative adjectives.
- Domain profile listing review-only divisions.
- Optional phases left undeclared.
- "Constraints: time" with no number.
