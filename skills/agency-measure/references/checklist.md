# MEASURE — gate checklist

## Domain gate (signed by an analytics/growth agent)

- [ ] Every metric has a value and a target.
- [ ] Every FRAME criterion has an outcome row.
- [ ] Every learning cites a number from Metrics collected.
- [ ] No learning is a summary of the campaign; all are backed by data.
- [ ] Findings that contradict the campaign's assumptions are stated
      plainly, not softened.

## Process gate (signed by PM)

- [ ] File lives at `docs/agency-flow/<slug>/05-measure.md`.
- [ ] Every follow-up has an owner.
- [ ] Every follow-up is marked `Ingested: yes` (into a backlog) or
      `Ingested: no` (with the reason).
- [ ] `## Assigned team` names domain agents and process steward.
- [ ] `## Gates` block present with both lines.
- [ ] No metric is presented without a target.

## Rejection triggers

- Metrics without targets.
- Learnings with no number behind them.
- Follow-ups with no owner.
- Criterion without an outcome row.
