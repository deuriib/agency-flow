# RESEARCH — gate checklist

Verify each line before signing either gate. Reject if any fails.

## Domain gate (signed by a domain agent)

- [ ] 1–5 research questions, each specific and answerable.
- [ ] Every question answered in `## Findings`.
- [ ] Every source is specific (URL, file path, interview ID).
- [ ] Findings contain concrete numbers or quotes — no generic claims.
- [ ] `## Findings → FRAME criteria` maps every question to a criterion
      preview (or explicitly marks it as PROPOSE-informative).

## Process gate (signed by PM)

- [ ] File lives at `docs/agency-flow/<slug>/00-research.md`.
- [ ] `## Assigned team` names both a domain agent and a process steward.
- [ ] `## Gates` block present with both lines.
- [ ] No research question was added mid-phase (compare to FRAME-declared
      scope if FRAME already exists).
- [ ] Every finding is traceable to a FRAME criterion that will exist.

## Common failure modes this checklist catches

- Research questions answered with "yes" or "it depends".
- Sources replaced by "based on experience".
- Findings without a link forward.
- Optional phase run without a declared `research? yes` in FRAME.
